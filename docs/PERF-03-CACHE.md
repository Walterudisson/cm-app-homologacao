# PERF-03: cache volátil DSIPS
Cache em memória por UID e geração, máximo 24 entradas armazenadas; catálogos (materiais, categorias, locais) TTL de 60 s, demais dados (responsáveis, posições, cautelas, unidades, posse) somente coalescência de solicitações simultâneas, nunca reuso de resposta concluída. Histórico e BI permanecem consultas diretas. Atualizar invalida cache; mudança de autenticação limpa; operações de gravação invalidam antes e no finally (incluindo falha de resposta), inclusive catálogo, para evitar reutilizar informação modificada. Durante escrita não reter catálogos novos. Respostas de geração inválida rejeitadas; falhas não armazenadas. Sem localStorage/IndexedDB/cache persistente adicionais. TTL não equivale a atualização em tempo real entre dispositivos; Atualizar força nova consulta SDK. Não altera backend, regras, índices, dados ou PRD. Paginação remota, estoque mínimo e demais dependências de backend permanecem suspensas. QA-01/02 próximas etapas.
