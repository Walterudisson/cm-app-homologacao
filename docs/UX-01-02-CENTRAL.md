# UX-01 / UX-02 — CMAPP

Base visual incremental: superfícies, espaçamento, hierarquia, ícones grandes e cards acionáveis inspirados no AppDashboard, sem importar dependências ou fontes não verificadas. O pacote PRO completo não foi localizado.

Central de Trabalho: módulos autorizados somente; sem métricas fictícias; Patrimônio abre o Painel existente e DSIPS abre Cautelas até a UX-03. Conferente patrimonial conserva início e tutorial existentes; demais gestores/admin entram na Central. Conta sem módulo permanece no perfil. Não altera autenticação, regras ou backend. Os temas completos ficam para revisão visual posterior; componentes usam as variáveis do shell existente.

Homologação: desktop e mobile, navegação de ida/volta, dois módulos para admin, somente módulos autorizados para gestor, preservação do Painel e do DSIPS. Próximas entregas UX-03 Painel DSIPS, UX-04 PDV, UX-05 gestão, UX-06 Patrimônio.
